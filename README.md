Simple Banking Management System in Python

Project Overviewb
This project is a python based Simple Banking Management System built using Python. It allows users to perform standard banking activities like creating an account, depositing and withdrawing money, checking balances, and viewing account information. 

The main objective is to understand core Object-Oriented Programmingconcepts like classes, objects, and basic data handling in Python.

Modules Covered
1. Account Management: Handles unique account generation, holder name, and balance state.
2. Banking Transactions: Manages deposit and withdrawal functions along with proper input validation.
3. User Interface: Menu-driven terminal input,output flow for smooth navigation.

Requirements
- Python 3.x
- Any terminal/ Command Prompt /IDE (VS Code, PyCharm, IDLE)
- Built using standard Python modules (random); no external libraries needed.

Run 
1. Download or copy (account.py, banking.py, user_interface.py)
2. Open terminal in the directory.
3. Run command: python main.py
